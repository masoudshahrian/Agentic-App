# 🚀 دستیار هوشمند بهینه‌سازی رزومه (AI CV Checker)
## سیستم انطباق هوشمند و بازنویسی رزومه مبتنی بر هوش مصنوعی (Gemini 3.6 Flash)

سیستم **AI CV Checker** یک ایجنت هوشمند، تخصصی و بهینه است که برای انطباق، بازنویسی و همگام‌سازی رزومه‌های کاری با شرح شغل‌های هدف (Job Descriptions) طراحی شده است. این ابزار با تحلیل عمیق شرح شغل، خلاءهای مهارتی و کلمات کلیدی گمشده در رزومه شما را شناسایی کرده و سپس رزومه را با تزریق واژگان تخصصی، افعال کنشی قدرتمند و فرموله‌سازی سنجه‌های عددی مجدداً بازنویسی می‌کند.

این پروژه به گونه‌ای توسعه یافته است که هم دارای یک **واسط کاربری پیشرفته (وب اپلیکیشن)** تحت وب باشد و هم یک **اسکریپت پایتون محلی (CLI)** بسیار ساده که توسعه‌دهندگان پایتون یا کاربران پلتفرم **Kaggle** و **Google Colab** بتوانند به آسانی و بدون نیاز به دانش فرانت‌اند، رزومه‌های خود را بهینه‌سازی کنند.

---

## ✨ ویژگی‌های برجسته پروژه
1. **استفاده از مدل فوق‌العاده سریع و رایگان Gemini 3.6 Flash:** استفاده کاملاً رایگان از سهمیه رایگان (Free Tier) گوگل بدون نیاز به داشتن حساب‌های دلاری یا پرداخت هزینه.
2. **پشتیبانی کامل از اسناد Word (.docx):** استخراج متن از فایل ورد ورودی و خروجی دادن یک فایل ورد شیک با قالب‌بندی و استایل‌های حرفه‌ای و مرتب.
3. **گزارش تحلیل خلاءها (ATS Gap Analysis):** محاسبه شاخص تطابق رزومه قبل و بعد از بهینه‌سازی و استخراج کلمات کلیدی گمشده.
4. **مربی آمادگی مصاحبه شغلی (Career Coach):** امکان گفتگو و سناریوسازی مصاحبه بر اساس رزومه جدید متمایز شده و شرح شغل هدف.
5. **قابلیت اجرای مستقیم در Kaggle و Colab:** توسعه بهینه به زبان پایتون خالص با کمترین وابستگی‌های خارجی.

## 💻 بخش ۱: راهنمای نصب و اجرای محلی (Local execution)
این روش برای افرادی طراحی شده است که می‌خواهند اسکریپت را بر روی کامپیوتر شخصی خود اجرا کنند.

### پیش‌نیازها
مطمئن شوید که پایتون ۳.۸ یا بالاتر روی سیستم شما نصب است.

### مراحل راه‌اندازی گام‌به‌گام

۱. **دانلود و استخراج فایل‌ها:**
   فایل‌های پروژه را از گیت‌هاب دانلود کرده یا پروژه را کلون کنید:
   ```bash
   git clone https://github.com/yourusername/cv-checker-ai.git
   cd cv-checker-ai
   ```

۲. **ساخت محیط مجازی (بسیار توصیه شده):**
   ```bash
   python -m venv venv
   # فعال‌سازی در ویندوز:
   venv\Scripts\activate
   # فعال‌سازی در مک یا لینوکس:
   source venv/bin/activate
   ```

۳. **نصب کتابخانه‌های مورد نیاز پایتون:**
   ما تنها از دو کتابخانه رسمی و استاندارد استفاده می‌کنیم:
   ```bash
   pip install google-genai python-docx
   ```

۴. **تنظیم کلید دسترسی Gemini به عنوان متغیر محیطی:**
   * **در ویندوز (Command Prompt):**
     ```cmd
     set GEMINI_API_KEY="کلید_کپی_شده_شما"
     ```
   * **در مک و لینوکس یا Git Bash:**
     ```bash
     export GEMINI_API_KEY="کلید_کپی_شده_شما"
     ```

۵. **اجرای اسکریپت بهینه‌ساز:**
   فایل رزومه فعلی خود را (می‌تواند متنی یا `.docx` باشد) و متن شرح شغل هدف را آماده کنید. سپس دستور زیر را برای بهینه‌سازی اجرا کنید:
   ```bash
   python cv_checker_agent.py --resume my_resume.docx --jd target_job_description.txt --output tailored_resume.docx
   ```

   **پارامترهای قابل تنظیم:**
   * `--resume`: مسیر فایل رزومه فعلی شما (فرمت Docx یا Text).
   * `--jd`: مسیر فایل متنی شامل شرح شغل مورد نظر کارفرما.
   * `--style`: (اختیاری) مسیر یک رزومه نمونه که مایلید فرمت رزومه جدید شما شبیه به آن باشد.
   * `--output`: نام فایل خروجی نهایی به فرمت Word (پیش‌فرض: `optimized_resume.docx`).
   * `--mode`: حالت بهینه‌سازی که می‌تواند یکی از موارد زیر باشد:
     * `comprehensive`: بهینه‌سازی همه‌جانبه (پیش‌فرض).
     * `keywords`: تمرکز صرف روی کلمات کلیدی سیستم‌های غربالگری ATS.
     * `impact`: تمرکز بر فرموله‌سازی دستاوردها و افزودن سنجه‌های عددی.
     * `concise`: خلاصه‌سازی و فشرده‌سازی رزومه در قالب یک صفحه.

## 📓 بخش ۲: راهنمای اجرا در پلتفرم کگل (Kaggle Notebook)
اگر می‌خواهید این سیستم را بدون نصب هیچ برنامه‌ای و به صورت ابری در کگل (Kaggle) اجرا کنید، کافیست فایل **`cv_checker_kaggle_single_cell.py`** موجود در این پروژه را باز کرده، کل محتویات آن را کپی کنید و در یک سلول نوت‌بوک کگل پیست کرده و اجرا کنید!

این فایل تمام مراحل نصب پکیج‌ها، پردازش و ذخیره‌سازی را در یک اجرای پیوسته (Single Cell) برای شما انجام می‌دهد. همچنین می‌توانید کدهای زیر را به عنوان مرجع درون کگل استفاده کنید:

### گام اول: تنظیم کلید دسترسی در کگل
برای امنیت بیشتر، نباید کلید API خود را به صورت عمومی در کدهای کگل بنویسید:
1. در دفترچه یادداشت (Notebook) کگل خود، از منوی بالا به بخش **Add-ons** بروید و گزینه **Secrets** را انتخاب کنید.
2. یک Secret جدید با نام دقیق `GEMINI_API_KEY` ایجاد کنید و مقدار آن را کلید دریافتی خود از گوگل آی‌آی استادیو قرار دهید.
3. تیک دسترسی نوت‌بوک به این سکرت را فعال کنید.

### گام دوم: نوشتن و اجرای کد در خانه سلول کگل (توسط فایل cv_checker_kaggle_single_cell.py)
یک سلول جدید باز کنید و کدهای زیر (یا محتویات کامل فایل `cv_checker_kaggle_single_cell.py`) را برای نصب پکیج‌ها و اجرای فرآیند کپی و اجرا کنید:

```python
# ۱. نصب کتابخانه‌های پیش‌نیاز روی سرور کگل
!pip install -q google-genai python-docx

import os
from google import genai
from google.genai import types
from kaggle_secrets import UserSecretsClient

# ۲. دریافت ایمن کلید دسترسی از بخش سکرت‌های کگل
user_secrets = UserSecretsClient()
os.environ["GEMINI_API_KEY"] = user_secrets.get_secret("GEMINI_API_KEY")

# ۳. تعریف متن رزومه خام و شرح شغل هدف به صورت متغیر متنی مستقیم
# (شما می‌توانید این متن‌ها را با متن‌های واقعی خود جایگزین کنید)

raw_resume = """
علی علوی
برنامه‌نویس پایتون
ایمیل: ali@email.com | تلفن: 09123456789

درباره من:
من برنامه‌نویس پایتون هستم و کدهای بک‌اند می‌نویسم. به کار با دیتابیس‌ها و نوشتن وب‌سرویس‌ها علاقه دارم.

سوابق کاری:
برنامه‌نویس وب در شرکت آلفا (۱۴۰۰ تا کنون)
- نوشتن کدهای بک‌اند با جنگو
- کار با دیتابیس و رفع خطاها

مهارت‌ها:
Python, Django, SQL, Git, Linux
"""

target_job_description = """
نیازمند برنامه‌نویس ارشد پایتون (Senior Python Developer)
وظایف و نیازمندی‌ها:
- تسلط بر زبان برنامه‌نویسی Python و فریم‌ورک‌های مدرن نظیر FastAPI یا Django
- تجربه در پیاده‌سازی معماری‌های میکروسرویس و صف‌های پردازش ناهمگام با Celery و Redis
- توانایی بهینه‌سازی کوئری‌های پایگاه‌داده PostgreSQL
- آشنایی با داکر (Docker) و مفاهیم پایه‌ای استقرار سیستم‌ها
"""

# ۴. فراخوانی و بهینه‌سازی توسط ایجنت هوشمند CV Checker
print("[*] در حال آماده‌سازی و ارسال اطلاعات به موتور بهینه‌ساز Gemini...")

client = genai.Client()
system_instruction = "You are an elite, highly experienced technical recruiter and professional resume writer (ATS expert). Rewrite the resume to align perfectly with the target Job Description (JD)."

prompt = f"""
=== USER BASE RESUME ===
{raw_resume}

=== TARGET JOB DESCRIPTION (JD) ===
{target_job_description}

=== INSTRUCTIONS ===
Optimize this resume to match the target JD. Focus on injecting action verbs and quantifiable metrics.
Return your output as a strict JSON structure containing "optimized_markdown" and "analysis" with match scores.
"""

response = client.models.generate_content(
    model='gemini-3.6-flash',
    contents=prompt,
    config=types.GenerateContentConfig(
        system_instruction=system_instruction,
        temperature=0.15,
        response_mime_type="application/json"
    )
)

import json
result = json.loads(response.text)

# ۵. نمایش خروجی‌های بهینه‌سازی شده در نوت‌بوک کگل
print("\n" + "="*50)
print("            نتایج شگفت‌انگیز بهینه‌سازی رزومه            ")
print("="*50)
print(f"امتیاز انطباق قبلی: {result['analysis']['score_before']}%")
print(f"امتیاز انطباق جدید (ATS Approved): {result['analysis']['score_after']}%")
print(f"میزان بهبود شاخص: +{result['analysis']['score_after'] - result['analysis']['score_before']}%")

print("\n[+] کلمات کلیدی و تخصصی تزریق شده:")
print(", ".join(result['analysis']['tailored_keywords']))

print("\n[+] افعال کنشی قدرتمند استفاده شده:")
print(", ".join(result['analysis']['action_verbs_injected']))

print("\n[+] رزومه نهایی بهینه‌سازی شده (فرمت مارک‌داون):")
print("-" * 50)
print(result['optimized_markdown'])
print("-" * 50)

# ۶. ذخیره کردن رزومه نهایی در قالب فایل مارک‌داون در دایرکتوری کگل
with open("tailored_resume.md", "w", encoding="utf-8") as f:
    f.write(result['optimized_markdown'])
print("[+] فایل رزومه متمایز با موفقیت با نام tailored_resume.md در فضای کاری کگل شما ذخیره شد!")
```

## 📂 ساختار فایل‌های پروژه
توضیحات مربوط به فایل‌های اصلی پروژه برای آشنایی برنامه‌نویسان پایتون:
* **`cv_checker_agent.py`**: اسکریپت اصلی و مستقل پایتون که کارهای استخراج اسناد ورد، ارتباط با API هوش مصنوعی جمینای، پردازش پاسخ و تبدیل خودکار به فایل ورد نهایی را بر عهده دارد.
* **`cv_checker_kaggle_single_cell.py`**: نسخه تخصصی تک‌سلولی (Single-Cell) پایتون، طراحی شده به صورت کاملاً خودکفا جهت کپی و اجرای بی‌دردسر در پلتفرم‌های **Kaggle** و **Google Colab**.
* **`server.ts`**: بک‌اند وب اپلیکیشن که با Express توسعه یافته و فرآیندها را هندل می‌کند.
* **`src/App.tsx`**: فرانت‌اند شیک وب اپلیکیشن طراحی شده با Tailwind CSS و React جهت سهولت استفاده تعاملی کاربران.
* **`src/components/`**: دایرکتوری شامل کامپوننت‌های فرعی فرانت‌اند مانند پنل بهینه‌سازی، صفحه دانلود اسکریپت پایتون و ماژول چت با مربی شغلی.
